# Week Assessment 4 – SQL

## 📌 Project Overview
This repository contains my solutions for **Week Assessment 4**, focused on SQL concepts using the `bookmart` database. The assessment covers SQL joins, subqueries, window functions, and Common Table Expressions (CTEs).

## 🎯 Objectives
- Understand and implement different types of SQL joins.
- Use subqueries to retrieve data based on conditions.
- Apply window functions for ranking and analytical calculations.
- Use CTEs to simplify and organize complex SQL queries.
- Analyze book sales, revenue, authors, and genres.

## 🛠️ Technologies Used
- **SQL**
- **MySQL**
- **MySQL Workbench**

## 📚 Topics Covered

### Section A: SQL Theory
- INNER JOIN vs LEFT JOIN
- NATURAL JOIN
- UNION vs UNION ALL
- Subqueries and correlated subqueries
- Window functions
- Common Table Expressions (CTEs)

### Section B: Output Prediction
- Joins and self joins
- UNION operations
- Scalar subqueries
- Identifying books with no sales
- Aggregate functions
- Ranking books by price

### Section C: Practical SQL Queries
- INNER JOIN, LEFT JOIN, and RIGHT JOIN
- FULL OUTER JOIN simulation using UNION
- CROSS JOIN and self join
- UNION with subqueries
- IN, ALL, EXISTS, and NOT EXISTS
- Window functions: AVG, ROW_NUMBER, LAG, and SUM
- Running totals and ranking
- CTEs for sales analysis and revenue calculations
